# Speech-Recognition-to-Generate-Image
This project aims to develop a Speech-to-Image Generation System that converts spoken input into relevant images. The system is trained using a dataset of over 8,000 images and provides fast image retrieval within seconds. Users can also download the generated images directly from the application. A user-friendly and visually appealing UI/UX design has been implemented to enhance the overall experience. The system includes secure login and registration pages with database support for storing user information such as username, name, password, email address, and phone number. The home page features a background video and an interactive welcome box that appears when clicked. Each page contains AI-generated informational content explaining the benefits, workflow, and image conversion process of the project. Detailed descriptions are provided throughout the application to help users understand how speech input is processed and converted into corresponding images.
